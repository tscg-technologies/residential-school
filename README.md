# RESIDENTIAL SCHOOL

> **Tagline:** LEARN • LIVE • GROW  
> **Type:** Fictional Indian Residential / Boarding School Website  
> **Technology:** HTML5, CSS3, Vanilla JavaScript (No frameworks, No build step, No backend dependencies)

---

## 🏛️ Project Overview

**RESIDENTIAL SCHOOL** is a complete, multi-page, responsive, and modern website built for a fictional premium Indian residential institution. It embodies the values of academic excellence, pastoral student wellbeing, disciplined living, sports, cultural arts, and community fraternity.

## ⚡ Features & Vanilla JavaScript Interactions

1. **Sticky Header & Dynamic Shadow:** Activates smooth elevation on scrolling.
2. **Mobile Navigation Drawer:** Responsive slide-over hamburger menu with keyboard escape support.
3. **Active Nav Link Tracking:** Automatically reflects the current page.
4. **Scroll Reveal Animations:** Powered by `IntersectionObserver` for performant viewport reveals.
5. **Interactive Gallery Category Filtering:** Filter by Campus, Classrooms, Boarding, Academics, Sports, Arts, and Events.
6. **Accessible Lightbox Modal:**
   - Previous & Next navigation controls
   - Keyboard arrow (`←` / `→`) and `Escape` key support
   - Overlay click-to-close
7. **Admission Enquiry Form:**
   - Client-side validation (Required fields, email formatting, phone numbers)
   - Friendly demo confirmation alert with clear notice that no data is transmitted
   - Reset capabilities
8. **Contact Us Form:** Client-side validation with responsive feedback.
9. **Accessible Accordions:** Single/multi-expand FAQs with smooth height animations.
10. **Graceful Image Fallback:** Custom SVG placeholder applied on any missing asset.
11. **Smooth Back-to-Top Button:** Floating control appearing upon scroll depth.

## 🚀 How to Run

Simply double-click `index.html` or open it with any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari). No web server, node process, or build tooling is required.
